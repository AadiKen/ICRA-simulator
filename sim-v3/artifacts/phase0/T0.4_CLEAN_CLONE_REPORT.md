## Method

To avoid committing or publishing from the user's working branch, the Phase 0 candidate changes were copied into an isolated clone and committed there. A second empty directory was then cloned from that candidate commit. Setup in the second clone followed the README commands:

1. Clone the repository.
2. Enter `ICRA-simulator/sim-v3`.
3. Run `npm ci`.
4. Run `npm run build`.
5. Run `npm run serve:web`.
6. Open `http://localhost:8000/`.

The in-app browser confirmed the `BCOD-Sim Research Console` page, `Research console` heading, one Three.js canvas, Vehicle A selected, and no console errors or warnings. `npm run test:smoke` then advanced the simulator through three steps with `stopReason: null`.
